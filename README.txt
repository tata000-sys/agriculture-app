農業管理アプリ（植物イラスト27枚対応版）

内容
- index.html
- images/ に植物イラスト27枚（きゅうり・小松菜・イチゴ × 9状態）

使い方
1. ZIPを展開します。
2. GitHubの tata000-sys/agriculture-app リポジトリを開きます。
3. 既存の index.html をこの版で置き換えます。
4. images フォルダを丸ごとアップロードします。
5. manifest.json は既存のものをそのまま残します。
6. GitHub Pages の公開後、アプリを再読み込みします。

注意
- GoogleスプレッドシートCSVの接続先と、日時・土壌水分・照度の列名読み取りは既存版を引き継いでいます。
- 照度の境界値と土壌水分センサーの乾燥時／湿潤時ADC値は仮設定です。実測に合わせてアプリ画面で変更してください。
- 土壌水分率は乾燥時ADC値と湿潤時ADC値の2点校正による実験用の相対推定値です。体積含水率そのものではありません。
